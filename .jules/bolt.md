## 2024-05-18 - Missing Indexes on Frequently Queried Boolean Flags and Sorting Columns
**Learning:** Found an architectural anti-pattern where tables like `schemes`, `galleries`, `documentations`, `asesors`, and `tempat_ujis` were missing database indexes for the `is_active` boolean column, despite it being frequently queried in `where('is_active', true)` clauses across almost all frontend user-facing pages. Additionally, the `event_date` column in the `galleries` table was missing an index despite being heavily used for sorting (`latest('event_date')`). As data scales, querying unindexed fields causes full table scans which can become a significant performance bottleneck.
**Action:** When designing or reviewing models that will be frequently filtered (e.g. by status flags) or sorted (e.g. by date), always verify that the appropriate database indexes are in place to prevent table scans and ensure query efficiency.
