## 2024-03-24 - N+1 Query on Asesor Schema
**Learning:** In the `AsesorController::index`, we are eager loading `scheme` using `Asesor::where('is_active', true)->with('scheme')->get()`. However, `Scheme::where('is_active', true)->get()` is accessed frequently in `HomeController`, `RegistrationController`, and `SkemaController`. Caching these often-accessed models globally could offer a measurable improvement, but currently, they aren't cached. Another candidate is caching the result of `Asesor::where('is_active', true)->with('scheme')->get()` since the list of active assessors and their schemes doesn't change frequently.
**Action:** Implement caching for active schemes and active assessors in their respective controllers, using Eloquent model events for cache invalidation, ensuring cache consistency.
